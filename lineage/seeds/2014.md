## Section 6 — Growth Loop

Each hub-orchestrated tick, on a checkout of this repo:

1. **check-lifecycle** — decide grow / replant / consolidate.
2. **plan-roadmap** — choose the next 1–3 items (`ROADMAP.md`).
3. **Content** (Haiku → Sonnet → Opus escalation) — research (≥2 sources) and
   write posts via `add-topic` / `deep-dive`; update the README table.
4. **build-structure** — refresh section indices, `/news/` landing, nav,
   previews, and the timeline.
5. **sync-seed** — regenerate seed.md sections 1–7.
6. **encode-seed** — append one entry to the Evolution Log (Section 8).
7. **publish** — commit and push new content + telemetry to `main`.

## Section 7 — Rebuild Procedure

To reconstruct this repository from the DNA:

1. Provision the Pages scaffold (`_config.yml`, favicon, `_data/navigation/main.yml`)
   via the hub's `provision-org-sites.rb`; set `remote_theme: bamr87/zer0-mistakes`.
2. Stage the canonical framework into `.github/` and the `.claude/` adapters.
3. Recreate content from Section 4: one post per topic at
   `_posts/<slug>/<YYYY-MM-DD>-<topic>.md` with `title` / `date` (single ISO) /
   `categories` / `tags` / `excerpt` / `preview` front matter, verified against
   ≥2 sources.
4. Run **build-structure** to regenerate the section indices, `/news/` landing,
   navigation, preview SVGs, and `TIMELINE.md`.
5. Run **sync-seed** to regenerate Sections 1–7; preserve Section 8 verbatim.
6. Rebuild the README knowledge table from the article set.
